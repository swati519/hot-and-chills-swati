# Hot and Chills Cafe

A premium, responsive cafe website built with HTML, CSS, and vanilla JavaScript.

## Features
- Modern cafe landing page with sticky navigation and smooth scrolling
- Premium coffee shop branding with warm coffee-inspired color palette
- Menu section with category filtering for Coffee, Fast Food, and Desserts
- Interactive shopping cart with add, remove, quantity controls, and localStorage persistence
- Demo checkout flow clearly labeled as a non-payment example
- Offer banners, gallery, reviews, contact form, and reservation form
- Responsive layout for desktop, tablet, and mobile screens
- GitHub Pages-ready static website with relative file paths

## Project structure
```text
hot-and-chills-swati/
├── index.html
├── style.css
├── script.js
├── README.md
```

## How to run locally
1. Clone the repository or download the project files.
2. Open `index.html` directly in a browser, or run a simple local server from the project folder:

```bash
python3 -m http.server 8000
```

3. Visit `http://localhost:8000` in your browser.

## GitHub Pages
This project is ready to publish on GitHub Pages as a static website. If using the repository settings:
1. Go to repository settings.
2. Open Pages.
3. Set the source to the default branch and root folder.
4. Save changes.

The site will be accessible via a GitHub Pages URL once published.
